# Episode 2 shot list: The Lost Sheep (Luke 15:1-7)

DRAFT by Claude for Dominique. One row per shot; IDs match `episode.yaml` and the file names in
`inputs/clips/` (or `inputs/stills/` for STILL shots). Seconds are estimates at ~145 words per minute;
the build stretches or trims every shot to fit her real recording, and no shot should end up over ~29 s.

**How to use the prompts in Google Flow (Veo)**
1. Every prompt = the **STYLE BLOCK** + the row's prompt. Where a row names a character in CAPS
   (e.g. SHEPHERD), paste that character's line from the sheet below in its place.
2. Settings: 16:9, 8-second clip, 1080p. Download, then rename to the shot ID (e.g. `H1.mp4`).
   Flow audio is stripped automatically by the build; don't worry about it.
3. For consistency, generate one clean reference still of each main character first (SHEPHERD,
   LOST SHEEP, JESUS, PHARISEES, TAX COLLECTOR) and reuse it as an ingredient/reference image
   for every clip that character appears in.
4. **STILL** = make a single image instead of a clip (save as `inputs/stills/<ID>.png`). The
   parallax tool or the slow push-in animates it. These are cheaper and good for quiet moments.
5. Re-roll anything where Jesus looks comic, goofy or exaggerated, where any text/letters appear
   in frame, or where someone appears to be talking (we never lip-sync).
